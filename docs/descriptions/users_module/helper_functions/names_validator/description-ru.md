# validate_name

**Модуль:** `users/utils/validators.py`
**Используется в:** `validate_first_name`, `validate_last_name`, `validate_middle_name`
(валидаторы полей в схемах пользователей)

## Назначение

Проверяет и нормализует часть имени (имя, фамилию или отчество) перед
сохранением. Гарантирует чистые однострочные имена в единой форме, чтобы поиск
и сравнение работали предсказуемо.

## Сигнатура

    validate_name(value: str, field: str) -> str

| Параметр | Описание |
|---|---|
| `value` | Исходная строка, отправленная клиентом. |
| `field` | Идентификатор поля (`first_name`, `last_name`, `middle_name`). Используется для кода ошибки и читаемого названия в сообщении. |

**Возвращает:** нормализованное имя.
**Исключение:** `PydanticCustomError`, возвращается как ошибка 422 с указанием поля.

## Шаги обработки

1. Нормализация пробелов: удаляются пробелы по краям, любая последовательность
   пробельных символов заменяется одним пробелом.
2. Нормализация Unicode в форму NFC, чтобы у буквы с диакритикой была единая запись.
3. Проверка длины.
4. Проверка символов и расположения разделителей.
5. Проверка, что ни одно слово не смешивает латиницу и кириллицу.
6. Возврат нормализованного значения. Регистр букв сохраняется.

## Правила валидации

| Правило | Значение |
|---|---|
| Длина | 3-30 символов после нормализации |
| Допустимые буквы | Английские (A-Z, a-z), латиница с диакритикой (À-ÖØ-öø-ÿ), русские (А-Я, а-я, Ё, ё) |
| Допустимые разделители | Пробел, дефис (`-`), апостроф (`'`) |
| Цифры и прочие символы | Запрещены |
| Расположение разделителей | Только между двумя словами (группами букв) |
| Повторяющиеся или соседние разделители | Запрещены |
| Смешение алфавитов | Одно слово не может содержать и латиницу, и кириллицу |

## Коды ошибок

| Код | Условие |
|---|---|
| `invalid_<field>_length` | Длина после нормализации вне диапазона 3-30. |
| `invalid_<field>_characters` | Недопустимый символ либо неверно расположенный или повторяющийся разделитель. |
| `invalid_<field>_mixed_scripts` | Слово содержит и латинские, и кириллические буквы. |

## Примеры

| Ввод | Результат |
|---|---|
| `Anna Mary`, `van de Sarr` | Принято |
| `Jean-Luc`, `O'Brien`, `José`, `Иван` | Принято |
| `Anna Иванова` | Принято (каждое слово в одном алфавите) |
| `  van   de   Sarr  ` | Принято, возвращается `van de Sarr` |
| `Al`, имя из 31 символа | Отклонено, длина |
| `Anna1` | Отклонено, символы |
| `Anna--Mary`, `Anna - Mary` | Отклонено, повторяющиеся разделители |
| `-Anna`, `Anna-` | Отклонено, разделитель на краю |
| `Аnna` (кириллическая А) | Отклонено, смешение алфавитов |

## Примечания по реализации

- Регистр сохраняется (`McDonald` остаётся `McDonald`).
- Длина проверяется здесь, а не через `Field(min_length=...)`, потому что
  ограничения Field выполняются до нормализации. В схеме остаётся только
  щедрый `max_length` как защита от слишком больших входных данных.
- Слова со смешанными алфавитами отклоняются, чтобы исключить визуально
  похожие символы, которые ломают поиск и сравнение.

## Ограничения

- Другие алфавиты и буквы Latin Extended-A (ł, ş, č, ğ) не поддерживаются.
- Типографский апостроф (`’`) не принимается, только `'`.
- Смешение алфавитов в разных словах допускается.
