# validate_name

**Модуль:** `users/utils/validators.py`
**Используется в:** `validate_first_name`, `validate_last_name`, `validate_middle_name`

## Назначение

Проверяет и нормализует часть имени (имя, фамилию или отчество), чтобы
сохранялись чистые однострочные имена с единообразным регистром.

## Сигнатура

    validate_name(value: str, field: str) -> str

| Параметр | Описание |
|---|---|
| `value` | Исходное имя, отправленное клиентом. |
| `field` | `first_name`, `last_name` или `middle_name`. Используется для кода ошибки и названия в сообщении. |

**Возвращает:** нормализованное имя.
**Исключение:** `PydanticCustomError`, возвращается как ошибка 422 для поля.

## Шаги обработки

1. Удаляются пробелы по краям, любая последовательность пробельных символов
   заменяется одним пробелом.
2. Проверяется общая длина.
3. Проверяется структура по допустимому шаблону.
4. Каждая группа букв приводится к виду «первая заглавная, остальные строчные».

## Правила валидации

| Правило | Значение |
|---|---|
| Длина | 2-30 символов всего, включая пробелы и разделители |
| Буквы | Только английские (A-Z, a-z) |
| Слова | От 1 до 3, разделены ровно одним пробелом |
| Букв в группе | Не менее 2, включая части до и после дефиса или апострофа |
| Разделители внутри слова | Не более одного дефиса (`-`) или прямого апострофа (`'`) на слово, только между двумя группами букв, без пробелов вокруг |
| Цифры и другие символы | Запрещены |

## Коды ошибок

| Код | Условие |
|---|---|
| `invalid_<field>_length` | Длина после нормализации вне диапазона 2-30. |
| `invalid_<field>_characters` | Структура или символы нарушают правила. |

Проверка длины выполняется первой, поэтому пустое значение, одна буква или
значение длиннее 30 символов возвращает ошибку длины.

## Примеры

| Ввод | Результат |
|---|---|
| `umar`, `UMAR`, `UmAr` | Принято, `Umar` |
| `  Umar   Ali  `, `Umar<TAB>Ali` | Принято, `Umar Ali` |
| `Umar Ali Name` | Принято |
| `umar-ali` | Принято, `Umar-Ali` |
| `Umar'Ali` | Принято |
| `Umar-Ali Smith-Jones` | Принято (один разделитель на слово) |
| `Um` | Принято |
| `LessThanThirtyOneNames` | Принято, `Lessthanthirtyonenames` |
| Пустая строка, одни пробелы, `U` | Отклонено, длина |
| 31+ символ | Отклонено, длина |
| `Umar Ali Name Extra` | Отклонено, 4 слова |
| `Umar - Ali`, `Umar -Ali`, `Umar- Ali`, `Umar ' Ali` | Отклонено, пробелы вокруг разделителя |
| `-Umarali`, `Umarali-`, `'Umarali`, `Umarali'` | Отклонено, разделитель на краю |
| `Umar--Ali`, `Umar''Ali` | Отклонено, повторяющийся разделитель |
| `U-mar-Ali`, `U'mar'Ali`, `U'mar-Ali` | Отклонено, два разделителя в одном слове |
| `U'mar`, `Um-m`, `Um m`, `Umar A` | Отклонено, в группе меньше 2 букв |
| `O'Brien`, `D'Angelo` | Отклонено, в группе меньше 2 букв |
| `Umar’Ali`, `Umar—Ali` | Отклонено, не прямой апостроф и не дефис |
| `Умарали`, `Ùmäřáľ` | Отклонено, не английские буквы |
| `123Umarali`, `Umar123ali`, `Umarali123` | Отклонено, цифры |
| `Umar_Ali`, `~!@#$%Umarali` | Отклонено, символы |

## Примечания по реализации

- Длина проверяется здесь, а не через `Field(min_length=...)`, потому что
  ограничения Field выполняются до нормализации. В схеме остаётся только
  щедрый `max_length` как защита от слишком больших данных.
- Принудительный регистр делает сохранённые имена единообразными для поиска и
  отображения.
- Лимит 30 символов соответствует колонке `String(30)`, поэтому значение не
  может её превысить.
- Правило «2 буквы в группе» применяется к каждой группе букв, это
  упрощает шаблон.

## Ограничения

- Имена с однобуквенным префиксом, например `O'Brien` и `D'Angelo`, нельзя
  зарегистрировать.
- Регистр принудительный: `McDonald` становится `Mcdonald`, а `van de Sarr`
  становится `Van De Sarr`.
- Однобуквенные слова (`A`, `J`), не английские буквы, буквы с диакритикой и
  типографский апостроф (`’`) не принимаются.
- Имена из более чем трёх слов не принимаются.
